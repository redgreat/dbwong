# 需求与验收基线

使用者为 DBA，其中获授管理角色的人员可进入 Admin。以下编号用于需求、实施和验收记录。

| 编号 | 使用场景和验收条件 |
| --- | --- |
| R01 登录与选库 | 两个不同授权的 DBA 登录后各自看到对应连接；按连接 ID 直接请求未授权库须被拒。选库后直接执行 SQL，全程无需输入或下载数据库密码。 |
| R02 连接与账号管理 | 管理员登录 Admin，创建账号、轮换密码、停用账号，登记云内或自建库、测试连接、改密、停用连接。停用后已有会话的新请求也被拒。普通 DBA 直接调用管理 API 返回无权访问。 |
| R03 内置工具授权 | 管理员给 A 在测试连接分配元数据工具，A 可列对象但不能执行 Agent 查询；撤权后在同一运行中再次调用即被拒。B 重用 A 的调用号不能读取其结果。 |
| R04 SQL 开发 | 展开库、schema、表、列、索引，打开多标签；提供高亮、补全、格式化、选中执行、整脚本执行、查询历史与执行计划。测试库验证事务回滚、多语句结果、超时及取消。 |
| R05 数据和结构 | 可分页查看、筛选、排序和复制结果；有主键且有写权时可编辑表行，提交前展示 SQL。表结构和索引变更可预览并保存为发布脚本。 |
| R06 Excel 导入 | 选择 XLSX 工作表、表头行和目标表，映射字段，预览样例及空值规则后提交。校验必填项、日期、数值精度；错误给出表格行列。首期导入已有事务表，失败回滚整批。覆盖中文列名、空工作表、长编号、重复主键。 |
| R07 Excel 导出 | 从表或查询结果导出 XLSX，可选列及表头；明确区分当前页与完整筛选结果，超限给出提示，不静默截断。验证跨页行数、高精度小数和带前导零的文本编号；文本以文本单元格写入。导入导出均核验连接权限并记录行数和结果。 |
| R08 个人云脚本 | 保存、命名、查找、比较版本并打开旧版本；换浏览器登录后仍可继续编辑。第二个账号不能通过版本 ID 读取；并发保存冲突时保留两端正文供处理。 |
| R09 测试到生产 | 使用初始化 DML 和结构变更 DDL 各走一次测试、选目标、看差异、确认、发布、查历史。测试失败或版本变化后无法发布；重复点击只产生一次执行。非事务 DDL 中断后可定位最后确认成功的步骤。 |
| R10 服务端审计 | 从工作台、内置 Agent 工具、Excel、发布及 Admin 各执行一次成功或拒绝操作，管理员可按账号和连接检索并关联请求号；检查凭据脱敏。审计不可写时禁止新执行。 |
| R11 客户端体验 | 在亮、暗主题下分别完成选库、执行选区、查看结果、展开执行消息。切换标签能辨认目标环境；执行中可见取消动作，失败保留 SQL 和错误位置（驱动提供时）。 |
| R12 个人模型与 Token | 两个账号分别选择服务商和模型；切换账号、退出或刷新后无法复用旧 Token。在浏览器网络记录中核对 Token 仅到指定模型端点。认证失败、跨域失败可辨别并能重新配置。 |
| R13 AI 辅助开发 | 在选定测试库让 Agent 读取已授权的表结构、生成方言正确的 SQL、解释只读查询错误；比较并采纳修改后由 DBA 执行。拒绝发送行样本后检查后续模型请求；取消后不再发下一轮。尝试调用写入或发布工具应被拒并可追溯。 |
| R14 五引擎验收 | 三个关系库分别跑对象树、查询、Excel 往返、个人版本和测试到生产发布。MSSQL 额外覆盖 GO 和多结果集；Mongo 验证嵌套文档与投影分页；Redis 验证 SCAN 续页、不同键类型及键过期。两种非关系库验证隐藏写入口且服务端拒绝相应请求。 |

## 裁剪边界

以 dbx 的对象浏览、查询编辑器、网格编辑、执行计划、数据导入导出为工作台基线。首期聚焦 XLSX，暂缓完整库导出、ER 图、数据生成、连接迁移、驱动商店及第三方 Agent 接入。dbflux、Rustable 与 racewong 仅供实现分层和交互参考。公司特有范围限定为本地 AI 辅助开发、账号与内置工具授权、Admin、审计、个人云脚本和发布。版本历史采用管理库实现；首期发布由有权限的 DBA 确认，无额外审批角色。
