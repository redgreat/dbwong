### M1 账号生命周期（R02）

Admin 支持停用、恢复普通 DBA 和重置密码。停用和重置会清理已有会话，操作和审计同事务提交；恢复账号后须重新登录。Windows Rust 构建及格式检查通过。独立 PostgreSQL 17.7 新库上，tests/smoke.py 验证后台角色隔离、撤权、停用后拒绝登录、恢复后旧会话失效、重置后旧密码及旧会话失效、新密码可登录。前端脚本语法检查通过，页面点击待验收。连接编辑与探测、内置工具授权和调度、审计检索及中断演练仍在 M1 范围内。

### M1 连接维护与 PostgreSQL 探测（R02、R10）

五种引擎均可在线修改连接名、环境、凭据及启用状态，连接 ID 与授权保持关联。停用后从 DBA 列表消失；恢复后原授权生效。PostgreSQL 的测试按钮从服务端使用已保存的凭据建立会话并执行 SELECT 1，超时为 5 秒；结果通过开始事件 ID 关联审计。其余四种驱动的协议级探测待实现。
